# Лабораторна робота №1. Основи функціонального програмування у Python

**Варіант 6:** Система доставки.

## Опис завдання
Реалізовано модуль розрахунку вартості доставки посилок та надбавок у функціональному стилі:
- вхідні дані посилок (`weight_kg`, `distance_km`, `delivery_type`, `paid`) не мутуються;
- розрахункове ядро повністю відділене від операцій вводу-виводу (`print`) та отримання системного часу (`time.time`);
- політики прийнятності (`AcceptFn`), базового тарифу (`TariffFn`), надбавок (`SurchargeFn`) та постачальник часу (`NowFn`) передаються через `typing.Callable`;
- використано фабрику вищого порядку `make_delivery_processor`, фабрику множників `make_multiplier` та композицію функцій `compose`.

## Структура проєкту
- `core.py` — чисті функції предметної області, типи `TypedDict` та фабрика обробників.
- `app.py` — оболонка побічних ефектів (тестові дані, інжекція `time.time`, форматований вивід звіту).
- `tests/test_core.py` — `pytest`-тести на референтну прозорість, відсутність мутацій та коректність `Callable`-політик.
- `requirements.txt` — залежності для тестування, перевірки типів та лінтингу.

## Встановлення та запуск

```bash
python -m venv .venv
source .venv/bin/activate  # для Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Запуск програми
```bash
python app.py
```

### Запуск тестів і перевірок якості коду
```bash
pytest -v
mypy --strict core.py app.py tests/
ruff check .
black --check .
```
